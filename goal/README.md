## 版本规则

- 每版保存目标、相对上版变化、固定配方、运行日志、结果与下一步判断。
- 同一配方的种子、重跑、故障恢复使用不同 run ID；改变研究问题、模型组合、数据协议或主要方法时创建下一版。
- 已运行的配置及已完成结果不可覆盖。修正通过追加 journal 记录、新 run 或新版本完成。
- 一次 run 的事件流和中途 checkpoint 可持续追加；最终 manifest、metrics 和产物索引只创建一次。
- 配置、样本 ID、指标及记录提交 Git；完整预测、原始数据、模型和训练 checkpoint 留在服务器，记录绝对路径与校验值。
- 公共实现保留在 `src/cope/`，版本目录不复制框架代码。数据与权重缓存可跨版本复用，输出目录不可复用。
- 新版本建立时，先在此表登记问题、状态和链接。失败或不确定结果也必须记录，不自动晋级。
