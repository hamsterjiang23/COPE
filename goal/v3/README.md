相对 v2：学生跳过 Prefill 改为候选路线而非所有实验的硬约束；两端冻结仍是硬约束，不使用 LoRA。暂不做多宽度、跨学生或跨数据集。固定 Qwen3-14B → Qwen3-1.7B，以接入方式 × 教师状态层位筛选。

| 接入方式 | 教师层位 | 学生问题可见性 | 说明 |
|---|---|---|---|
| embedding 连续前缀 | 最后一层 / 第 20 块后 | 完整问题 | 32 个前缀与问题 embedding 拼接，学生正常 Prefill |
| kv_add 附加 KV | 最后一层 / 第 20 块后 | 完整问题 | 合成 32 个 KV 记忆位置，学生问题 Prefill 可读取；不是 C2C 的逐位置原生 KV 融合 |
| kv_replace 替代问题 KV | 最后一层 / 第 20 块后 | 不接收问题 token | 合成 32 个 KV 记忆位置，学生仅接收固定启动 token 后 Decode；不是重建原生 KV 的主张 |

共 6 个组合。教师一次处理问题及固定提示，不接收参考答案。取未 padding 的所选层序列，按位置平均池化为 32 slot，共享 MLP 输出 512 维 latent。前缀组线性映射到学生 2048 维；KV 组每个学生层使用 rank=32 的瓶颈 MLP，生成 8 个 KV 头 × 128 维的 K/V，并按学生 k_norm 与 RoPE 处理 K 一次。两类 reader 的参数量不同，均单列实测，不声称等参数或等 FLOPs。第 20 块后表示没有最终输出 norm，末层表示包含最终 norm；层位与原生归一化语义一起作为候选因素。

跨卡只复制 [1,32,512] FP32 latent，共 65,536 bytes/题，学生侧展开成 embedding 或各层 KV；不将学生侧展开容量称为通信压缩收益。

kv_replace 启动约定：取所有问题 chat prompt 共用的最后一个 token 作为固定启动 token，token ID 在准备数据时核验并登记；合成 KV 位置为 0–31，启动位置为 32。后续生成 token 正常 embedding/Decode。原始问题 token 不进入该学生分支。

数据来自固定 GSM8K main/train revision，排除 v1/v2 所用全部 1,152 个样本 ID，按问题去重。固定划分 512 训练、32 校准、64 开发、256 留出，所有划分互斥。只按训练长度排除超长样本，留出不按参考答案长度过滤；官方 test 不使用。校准输出只记录，不自动改提示或解析规则；若需改协议另建版本。

执行：两个原生学生 cache 交接检查 → 每个候选两批真实模型梯度探测 → 校准/开发学生基线 → 各候选 16 题、16 步学习检查 → 通过者重新初始化训练 128 步 → 正确及推理时错配的开发集评测。训练为 microbatch=1、累积=8、AdamW lr=3e-4、clip=1，每组曝光训练集两遍；每 32 步保存接口、优化器与 RNG。候选从相同种子初始化，同形状组合共享初始化规则。

开发筛选分数为 min(正确−学生基线，正确−推理错配)；必须 >0，择最高者，平局按 ID 字典序，仅选 1 个。没有候选通过则停止，留出不评测，不扩大搜索。入选结构额外从头训练可学习常量和训练时错配控制，各 128 步，样本顺序相同。错配从同划分选择不同 donor，训练每 epoch 更新，评测固定配对并记录 ID。
